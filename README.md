# J Tools - Panel Gamer Futurista 🚀

Aplicación Android nativa con diseño neón futurista, optimización de rendimiento y controles flotantes avanzados.

## Características
- **Inicio**: Monitoreo de sesión, controles flotantes, enlaces sociales y grabador de pantalla integrado.
- **Gestión**: Ajuste de transparencia, posición de botones flotantes y funciones futuras.
- **Ajustes**: Personalización completa del logo J, temas de color, tamaños de botones y permisos del sistema.
